# Ghostwriter 

A personal ghostwriting portfolio designed to showcase writing, build credibility, and connect with potential clients.

 **Live:** https://ghost-writer-nine.vercel.app/

---

## About

Ghostwriter is a modern portfolio website created for a professional ghostwriter.

It brings together writing samples, services, personal branding, and a simple way for potential clients to get in touch.

The website is designed to feel personal, editorial, and focused on one thing:

**great writing that speaks for itself.**
